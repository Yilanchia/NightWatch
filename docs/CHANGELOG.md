# 变更记录

## v0.2.0 · 2026-11-23

多端值守。

- 节点身份（Ed25519，ID = 公钥指纹）+ 签名摘要（发现 + 健康，不含原始事实）；
- `pull-correlate`：通过 SSH 拉各节点摘要 → 登记 → 幂等摄入 → 按事实 key 关联；
  跨端高危退出码 2；
- 协调端状态可重建；`ingestBundle` 拒绝更旧序号（重放/乱序），`verifyBundle` 可选新鲜度；
- 告警纪律：分级、限频、安静时段、升级阶梯；出口投影脱敏；
- 出站推送 stage 1：内置 `node:https`，支持 json / wecom / feishu / text；默认只写本地文件；
- 只读面板新增"多端防护网"视图（节点清单 + 跨节点关联）；
- daemon 收到 SIGTERM 立即打断 sleep，`systemctl stop` 不再等一分钟。

验收：两台 Linux 主机各连续巡检（7 / 14 轮），两台 `acceptance` 四项全 PASS；
跨端关联出 2 条两台共同的高危发现。

## v0.1.0 · 2026-11-17

首个单机只读版本。

- 只读采集：端口、SSH 生效配置、备份年龄；
- 只追加 `watch.jsonl` + 可重建的 SQLite 物化视图；
- 基线差分、发现生命周期（持续 / 恢复 / 复发）、每日报告、检查盲区；
- 无模型巡检 `tick`、内置调度 `daemon`、健康查询、时间线；
- 只读面板（本地 HTTP + SSH 隧道）；
- 修复提案；执行入口默认不注册，一次性审批元数据就绪；
- 结构化调查判断（confirmed 必须命中真实观测）、pending 队列、确定性告警队列；
- 强制力探针与插件级策略决策点；出口投影与 canary 探针。
